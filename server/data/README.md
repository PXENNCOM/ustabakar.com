# tr-geo.json.gz

Türkiye il / ilçe / semt / mahalle / posta kodu verisi.

- Kaynak: https://github.com/epigra/tr-geozones (MIT lisansı, Copyright (c) 2019 Epigra)
- Veri, PTT'nin postakodu.ptt.gov.tr adresinde yayımladığı listeden derlenmiştir (10.08.2022 itibarıyla).
- Kayıt sayıları: 81 il, 973 ilçe, 2771 semt, 73304 mahalle.

İçe aktarmak için: `node scripts/import-geo.js`
